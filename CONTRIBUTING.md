# Contributing to ProofStack

ProofStack is a four-person team build. The goal is not for one person to finish fastest; the goal is to ship a coherent product with visible, substantive contributions from every teammate.

## Working agreement
- Use your own GitHub account. Never share credentials.
- Work in feature branches.
- Open pull requests before merging to the team branch.
- Keep commits focused and understandable.
- Surface blockers early in the team Slack thread.
- Never commit secrets or real organizational evidence.
- Prefer small, testable changes over large rewrites.
- State what you changed and how to reproduce it in the PR.

Suggested branch prefixes: `product/`, `evidence/`, `security/`, `evaluation/`, `docs/`.

## Definition of done
A change works locally, has relevant validation/tests, updates documentation where needed, contains no secrets/sensitive data, and leaves a clear contribution trail.

## Attribution
The final README will record specific contributions by each teammate: features, tests, evidence design, architecture, evaluation, security, documentation, or deployment work actually completed.
